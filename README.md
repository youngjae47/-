# 우리 가족 스케쥴

가족 모두가 함께 보고 고칠 수 있는 공유 일정 캘린더 웹앱입니다. 기획 내용은 [가족스케쥴.md](가족스케쥴.md)에 있습니다.

## 실행 방법
`index.html`을 브라우저로 열면 됩니다. 설치나 빌드는 필요 없습니다.

## 지금 되는 것 (1단계: 가족 일정 달력)
- 월별 달력 보기, 이전·다음 달 이동, 오늘로 돌아가기
- 날짜를 누르면 그날 일정 목록, `＋` 버튼으로 일정 추가
- 일정 고치기 · 지우기 (제목, 누구, 시작·끝 날짜, 시간, 메모)
- `가족 / 아빠 / 엄마 / 수현` 색 구분, 위쪽 버튼으로 보고 싶은 사람만 골라 보기
- 공휴일 · 대체공휴일 자동 표시 (2026~2027년)
- 휴대폰 화면 지원

## 알아둘 점
- 일정은 지금 **이 브라우저에만** 저장됩니다. 가족이 각자 휴대폰에서 같은 일정을 보려면 다음 단계에서 공유 저장소를 붙여야 합니다. (`js/store.js`만 바꾸면 됩니다.)
- 공휴일은 `js/holidays.js`에 들어 있습니다. 새해 공휴일이 발표되면 이 파일에 추가합니다.

## 파일 구성
```
index.html        화면 구조
css/style.css     디자인
js/holidays.js    공휴일 데이터
js/store.js       일정 저장 (localStorage)
js/app.js         달력 동작
```
