# 우리 가족 스케쥴

가족 모두가 함께 보고 고칠 수 있는 공유 일정 캘린더 웹앱입니다. 기획 내용은 [가족스케쥴.md](가족스케쥴.md)에 있습니다.

## 지금 되는 것
- 월별 달력 보기, 이전·다음 달 이동, 오늘로 돌아가기
- 날짜를 누르면 그날 일정 목록, `＋` 버튼으로 일정 추가
- 일정 고치기 · 지우기 (제목, 누구, 시작·끝 날짜, 시간, 메모)
- **반복 일정**: 매일 · 매주(요일 여러 개) · 매월 · 매년, 반복 끝나는 날 정하기
  - 반복 일정을 누르면 **이 날만 고치기 / 이 날만 지우기 / 모든 반복 고치기 / 모든 반복 지우기** 중에 고름
- `가족 / 아빠 / 엄마 / 수현` 색 구분, 위쪽 버튼으로 보고 싶은 사람만 골라 보기
- 공휴일 · 대체공휴일 자동 표시 (2026~2027년)
- **목표 간트차트 보드** (아빠 · 엄마 · 수현 탭)
  - 대분류 💪 건강 · 👨‍👩‍👧 가족 관계 · 🌱 자아실현 아래에 소분류 목표를 추가
  - 1년을 12달로 펼친 간트차트: 목표 기간이 막대로, 달성률만큼 막대가 채워짐, 오늘 위치에 빨간 선
  - 맨 위 요약: 전체 달성률, 대분류별 달성률, 목표 수 · 완료 수
  - 목표를 눌러 기간 · 달성률(슬라이더, ±10 버튼) · 메모 고치기, 이전 · 다음 해 보기
  - **연간 / 일별 보기**: 일별은 하루 한 칸, 가로 스크롤 (주말 · 공휴일 색 구분, 처음엔 오늘로 이동)
  - **막대 끌기**: 가운데를 끌면 기간 옮기기, 양 끝을 끌면 시작일 · 종료일 바꾸기 (하루 단위)
  - **순서 바꾸기**: 왼쪽 ⠿ 손잡이를 위아래로 끌기 (다른 대분류로 옮기면 대분류도 바뀜, 키보드 ↑↓도 가능)
  - **키워드 검색**: 가족 전체 목표에서 이름 · 메모 · 대분류로 찾기, 결과를 누르면 그 목표로 이동
- **이번 주 요약**: 달력 위에 이번 주(월~일) 가족 일정 수 · 사람별 개수, 다가오는 7일 일정과 공휴일 (오늘 · 내일 · D-3)
- **목표 달성 축하**: 달성률이 100%가 되면 색종이와 축하 창, 가족이 달성해도 내 화면에서 축하, 달성한 목표에 🏅
- **가족 전체 달성률**: 목표 화면 맨 위에 가족 평균과 아빠 · 엄마 · 수현 달성률 (누르면 그 사람 탭)
- **휴대폰 홈 화면에 추가**: 앱 아이콘으로 바로 열기, 인터넷이 끊겨도 화면이 열림 (안드로이드 설치 버튼, 아이폰 안내)
- **가족 공유**: 초대 링크 하나로 가족 모두 같은 달력을 실시간으로 보고 고침 (Firebase)
- 인터넷이 끊겨도 보고 입력할 수 있고, 다시 연결되면 자동으로 올라감
- 휴대폰 화면 지원

## 처음 설정하기 (한 번만)

### 1. Firebase 프로젝트 만들기 (무료)
1. <https://console.firebase.google.com> 에 구글 계정으로 들어가 **프로젝트 추가**를 누릅니다.
   - 이름은 자유 (예: `our-family-schedule`), Google 애널리틱스는 꺼도 됩니다.
2. 왼쪽 메뉴 **빌드 > Firestore Database > 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
3. Firestore 화면의 **규칙** 탭에서 내용을 모두 지우고, 이 리포지토리의 [`firestore.rules`](firestore.rules) 내용을 붙여넣은 뒤 **게시**합니다.
4. **프로젝트 설정(톱니바퀴) > 일반 > 내 앱 > 웹(`</>`)** 을 눌러 앱을 등록합니다. (호스팅 체크는 안 해도 됩니다)
5. 화면에 나오는 `firebaseConfig = { ... }` 값을 [`js/firebase-config.js`](js/firebase-config.js)의 `FIREBASE_CONFIG`에 붙여넣습니다.

> `firebaseConfig` 값은 공개돼도 괜찮은 값입니다. 일정은 보안 규칙과 **가족 코드**로 보호됩니다.

### 2. 인터넷 주소 열기 (GitHub Pages, 무료)
1. 이 리포지토리의 **Settings > Pages**
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 를 고르고 저장
3. 1~2분 뒤 `https://<깃허브 아이디>.github.io/<리포지토리 이름>/` 로 열립니다.

### 3. 가족 초대
1. 한 사람이 주소를 열면 **가족과 함께 쓰기** 창이 뜹니다. **새 가족 달력 만들기**를 누릅니다.
2. **링크 복사**를 눌러 가족 단톡방 등에 보냅니다.
3. 가족이 링크를 열면 바로 같은 달력에 들어옵니다. 휴대폰에서는 **홈 화면에 추가**해 두면 편합니다.

오른쪽 위 배지로 상태를 볼 수 있습니다: 🟢 가족과 공유 중 · 🟡 오프라인 · 🔴 연결 문제. 배지를 누르면 초대 링크를 다시 볼 수 있습니다.

## 알아둘 점
- **초대 링크를 아는 사람은 누구나** 달력을 보고 고칠 수 있습니다. 가족끼리만 나눠 주세요. 링크가 새어 나가면 **새 가족 달력 만들기**로 새 코드를 만들 수 있습니다. (예전 일정은 옮겨지지 않습니다)
- 가족 코드는 각 기기에만 저장되고 리포지토리에는 올라가지 않습니다.
- `js/firebase-config.js`를 비워두면(null) 예전처럼 **이 기기에만** 저장됩니다. 공유 전에 이 기기에 넣어 둔 일정은 연결 후 **가족 달력으로 옮기기**로 올릴 수 있습니다.
- `firestore.rules`가 바뀌면 Firebase 콘솔의 **규칙** 탭에 새 내용을 다시 붙여넣고 게시해야 합니다. (반복 일정, 목표 보드를 추가하면서 규칙이 바뀌었습니다)
- 화면 파일(js · css 등)을 추가하거나 이름을 바꾸면 `sw.js`의 `APP_FILES` 목록과 `CACHE` 이름의 숫자를 함께 바꿔 주세요. (홈 화면 앱이 새 파일을 받도록)
- 아이폰은 **사파리**에서 열어야 홈 화면에 추가할 수 있습니다. 카카오톡으로 받은 링크는 카카오톡 화면의 메뉴에서 다른 브라우저(사파리)로 열어 주세요.
- 공휴일은 `js/holidays.js`에 들어 있습니다. 새해 공휴일이 발표되면 이 파일에 추가합니다.

## 파일 구성
```
index.html              화면 구조
css/style.css           디자인
js/holidays.js          공휴일 데이터
js/recurrence.js        반복 일정 계산
js/firebase-config.js   Firebase 연결 설정 (직접 채우기)
js/store.js             일정 · 목표 저장 (Firestore 또는 이 기기)
js/goals.js             목표 간트차트 보드
js/celebrate.js         목표 달성 축하 (색종이)
js/app.js               달력 · 이번 주 요약 · 탭 · 공유 · 홈 화면 추가
manifest.webmanifest    홈 화면 앱 정보 (이름 · 아이콘)
sw.js                   서비스 워커 (인터넷 없이 열기)
icons/                  앱 아이콘
firestore.rules         Firestore 보안 규칙 (콘솔에 붙여넣기)
firebase.json           Firebase CLI · 에뮬레이터 설정 (테스트용)
```
